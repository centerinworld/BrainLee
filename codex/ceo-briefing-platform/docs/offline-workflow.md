# 오프라인 우선 작업 흐름

휴대폰 테더링 등 저데이터 환경에서 먼저 진행할 수 있는 작업만 정리한 문서입니다.

## 지금 가능한 일

- 브라우저에서 정적 프론트엔드 확인
- 로컬 선별 콘솔로 기사/경쟁사 후보 선택 흐름 검토
- 역할별 페이지 구조와 접근 정책 검토
- Google Calendar / RSS 연동 스텁 구조 점검
- API 계약과 화면 요구사항 정리

## 나중에 데이터 여유가 생기면 할 일

1. Python 설치
2. FastAPI 서버 실행
3. Google Calendar OAuth 설정
4. RSS 수집기 실제 연결
5. DB 저장과 사용자 인증 추가

## 로컬 콘솔 파일

- `local-console/company-news.html`
- `local-console/competitor-watch.html`

위 두 파일은 별도 설치 없이 브라우저에서 열 수 있습니다.

## 추천 확인 순서

1. 프로토타입 UI 확인
2. 로컬 선별 콘솔에서 전송 흐름 검토
3. 페이지/권한 정책 검토
4. 이후 실제 연동 범위 결정
