# 메타전략 회전수/트리거 제안 (2026-05-19)

## 1) 회전수(예산 관점)
현재 메타는 전략별 백테스트 거래수를 비중으로 합성한 "가중 회전수" 기준으로 추정함.

- 균형형 메타(5구간 합): 약 482.7건
- 보수형 메타(5구간 합): 약 439.8건

구간별(가중 거래수)
- 균형형: 121.5 / 82.0 / 97.7 / 88.8 / 92.8
- 보수형: 111.8 / 68.7 / 90.3 / 88.4 / 80.6

해석:
- 예산/운영 난이도를 고려하면 보수형이 실행 친화적.
- 실제 운용 전에는 메타 전용 실행기(동일자 중복체결 제거, 최소 주문금액, 수수료/슬리피지 반영)로 최종 회전수를 재측정해야 함.

## 2) 2020.03~2025.05 급등주 1차 분석
상승률 상위(표본): HD현대일렉트릭, 효성중공업, 한화에어로스페이스, 한미반도체, 일진전기, 알테오젠, 파마리서치, 태성, 한화엔진 등.

관찰:

- DART 수주 이벤트가 있는 종목은 강한 후행 추세가 자주 관찰됨(예: HD현대마린엔진, 알테오젠, 엠로).
- 다만 수주공시가 없는 급등주도 많아(테마/실적/수급) "공시 단독" 신호로는 부족.

## 3) 신규 매수 트리거(제안)
아래 4개 중 2개 이상 + 국면(stage1~3)일 때만 매수 허용:

1) 공시 트리거
- dart_contracts: ai_score >= 80 AND signal_strength >= 4
- contract_ratio_pct >= 10 (없으면 보수점수)

2) 수급 트리거
- investor_trading_daily 또는 price_history의 frn/inst 순매수 5일·20일 동시 양수

3) 추세 트리거
- 종가 > MA60 > MA120, 최근 20일 신고가 근접(상위 15%)

4) 이익/펀더멘털 트리거
- financial_data: 최근 공시에서 OP 흑자 + YoY 개선
- consensus_targets 상향 리포트(목표가/의견 상향)

진입 제한:
- stage4~5 또는 forced stage4/5 시 신규진입 금지
- 동일 섹터/테마 집중도 상한(예: 35%)

## 4) 매도/리스크 트리거(제안)
1) 하드 리스크 컷
- 종목 -8% 또는 포트폴리오 일중 -2.5% 초과 시 강제 축소

2) 이벤트 실패 컷
- 공시 기반 진입 종목이 T+20영업일 내 상대수익률(대비 KOSPI) 음수면 절반 축소

3) 추세 붕괴 컷
- MA60 이탈 2일 연속 + 외국인 5일 순매도 전환

4) 과열 이익보호
- +25% 이상 수익 후 고점 대비 -10% 이탈 시 부분익절

## 5) 실행 우선순위
1) 메타 실행기 구현(전략 신호 병합/중복 제거/체결 제약 반영)
