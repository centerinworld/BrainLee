# 가격 기준·자본행위 보정 엔진 감사

작성일: 2026-07-12

## 정책

- `price_history`: KIS 수정주가 수집을 지향하지만 과거 소스 혼재 위험이 있는 연구용 계열이다.
- `stock_price_daily`: 원주가·상장주식수·체결가격 검증용 계열이다.
- 원본 테이블은 수정하거나 덮어쓰지 않는다.
- 분할·병합·무상증자처럼 공시 유형과 주식수 변화가 함께 확인된 경우만 보정계수를 확정한다.
- 유상증자·CB·일반 주식수 증가는 발행가격과 권리 가치가 필요하므로 단순 주식수 비율로 가격을 보정하지 않는다.

## 신규 구성

- `price_series_registry`: 가격계열별 기준과 용도를 저장한다.
- `corporate_action_events`: 자본행위 날짜·유형·주식수 변화·보정계수·근거·신뢰도를 저장한다.
- `price_history_quality_v`: 가격 급변을 정상·자본행위 검토·설명되지 않은 급변으로 분류한다.
- `stock_price_daily_adjusted_v`: 확정된 자본행위만 원주가 OHLCV에 누적 적용한다.
- 생성기: `scripts/build_corporate_action_adjustment_engine.py`
- 자동 실행: 매 영업일 18:35 KRX 종목기본정보 수집 직후

## 차트 API 가격 기준

`GET /api/dashboard/chart/{stock_code}?days=365&basis=...`

- `research_adjusted`: 기존 `price_history`, 연구용 수정주가 지향·혼재 위험
- `execution_raw`: `stock_price_daily`, 원주가 체결 검증용
- `confirmed_actions_adjusted`: 확정 자본행위만 보정한 원주가 계열

각 응답 행에 `price_basis`를 포함한다.

## 남은 작업

1. 4,292개 설명되지 않은 급변을 소스 전환·정리매매·거래정지·실제 급등락으로 분류한다.
2. KIS 수정주가를 전 종목·전 기간 재수집해 `price_history` 혼재 구간을 별도 canonical 테이블로 재구축한다.
3. DART 원문에서 신주배정기준일, 권리락일, 분할·병합 효력일, 신주 상장일과 발행가액을 구조화한다.
4. 유상증자는 TERP 방식의 이론 권리락 보정계수를 별도 계산한다.
5. 모든 백테스트가 가격 기준을 명시하도록 API·함수 계약을 강제한다.
6. 기존 전략별 결과를 canonical 수정계열로 재실행해 결과 변화량을 비교한다.

## 안전 주의

- `price_history`를 `stock_price_daily` 값으로 직접 덮어쓰지 말 것.
- 확정되지 않은 주식수 비율로 과거 OHLCV를 자동 재작성하지 말 것.
- `confirmed_actions_adjusted`는 확정 이벤트 커버리지가 아직 낮으므로 완전한 수정주가로 표현하지 말 것.
