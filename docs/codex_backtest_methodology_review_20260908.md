# 백테스트 기반 전략 수립 방법론 검토

## 최종 판정

과거 데이터로 매수·매도 규칙을 발견하고 백테스트하는 접근은 적절하며 실제 운용 전략을
만드는 표준적인 출발점이다. 그러나 현재 선택된 전략의 백테스트 수익률은 미래 기대수익이나
실전 가능성을 입증하지 못한다. 현재 결과는 `연구 가설`로는 사용할 수 있지만 `주문 근거`로는
사용할 수 없다.

## 핵심 증거

- 선택 전략은 26개, 각 6개 구간으로 구성되지만 `2023-11-01~2024-12-31`과
  `2024-06-01~2025-05-31`이 약 7개월 겹친다. 따라서 6개 독립 표본이 아니다.
- 26개 전략의 기간 수익률 쌍별 상관계수 중앙값은 0.697이고 325개 조합 중 122개가
  0.8을 초과한다. 상관행렬의 참여율 기준 유효 독립 전략 수는 약 1.99개다. 전략 이름은
  많지만 실질적으로는 소수의 시장·팩터 노출을 반복하고 있다.
- 강세장이 결과를 크게 지배한다. KOSPI가 41.77% 오른 2020-03~2021-11에는 전략
  중앙값이 58.19%, KOSPI가 87.20% 오른 2025-06~2026-03에는 42.06%였다.
  반대로 KOSPI가 -20.90%였던 2021-12~2022-10에는 전략 중앙값이 -8.46%였고,
  26개 중 3개만 양수였다.
- 선택 전략 중 6개 구간 모두 양수인 것은 `v1_value` 하나뿐이다. 이것도 데이터 가용시점
  증빙을 통과하지 못했으므로 독립적인 실전 근거는 아니다.
- 선택 실행의 가격 무결성은 23/26만 통과했고, 지연 데이터 가용시점은 156개 구성요소 중
  24개만 통과했다. 정적 계약에는 P0 1건과 P1 29건이 남아 있다.
- 전진검증 통과 전략은 0개다. 최신 가상계좌는 golden_cross -13.74%(61일, 14회),
  contract_momentum +0.74%(30일, 6회)로 표본이 부족하다. recovery의 최근 기록도
  -2.51%(39일, 15회)였다.
- 백테스트는 D일 종가 신호를 D+1 시가에 체결하지만 기존 가상매매 엔진은 20분 주기의
  현재가로 주문한다. golden_cross의 포지션 수·트레일 값과 contract_momentum의 진입
  유효기간도 백테스트와 다르다. 이 결과끼리는 동일 전략의 재현 검증으로 비교할 수 없다.
- 운영 문서는 전진검증 최소 90일·30회 거래를 요구하지만 실제 검증 코드는 60일·20회다.
  정책과 코드가 불일치한다.

## 적절한 사용 범위

현재 백테스트는 다음 용도로는 유효하다.

- 아이디어와 인과 가설을 기각하는 용도
- 손실 국면, 회전율, 유동성 및 최대 낙폭을 파악하는 용도
- 동일한 체결 엔진에서 후보 규칙을 상대 비교하는 용도
- 데이터 누수와 구현 오류를 찾는 회귀 테스트

현재 백테스트는 다음 용도로 사용하면 안 된다.

- 최고 수익률 전략을 골라 미래 수익률로 제시
- 겹치는 6개 구간 평균을 독립적인 재현 횟수로 해석
- 같은 과거 구간에서 수십 번 조정한 규칙을 표본외 검증이라고 주장
- 백테스트와 구현이 다른 가상·실전 엔진의 결과를 직접 비교
- 전진검증 없이 자동주문 또는 자본 배분 비중을 확대

## 실현 가능한 검증 설계

1. 데이터는 모든 신호 입력에 `source_row_id`, `available_at`, `decision_at`을 저장하고
   `available_at <= decision_at`을 강제한다.
2. 단일 주문 엔진을 백테스트·가상매매·실전매매가 공유하게 하고 D일 신호, D+1 주문,
   정수주식, 수수료, 세금, 슬리피지, 거래정지 및 부분체결을 동일하게 처리한다.
3. 개발 구간과 최종 잠금 구간을 분리한다. 잠금 구간은 전략·파라미터 선택에 한 번도
   사용하지 않고 최종 1회만 평가한다.
4. 겹치지 않는 롤링 walk-forward로 학습·검증·테스트를 분리하고 각 테스트 구간의
   벤치마크 대비 수익, MDD, turnover, profit factor를 함께 기록한다.
5. 전략 수가 아니라 독립 팩터 수를 관리한다. 상관 0.8 이상 전략은 같은 군으로 묶고,
   군별 대표 전략만 전진검증한다.
6. 반복 탐색 횟수와 실패한 실험도 저장하고, 선택 성과에는 다중검정 및 과최적화 페널티를
   적용한다.
7. 최소 90일·완결거래 30건은 승격의 최저선으로 통일하되, 실제 자본 투입은 서로 다른
   시장 국면을 포함한 더 긴 전진 표본과 소액 수동 주문 검증 후 단계적으로 진행한다.

## 결론

현재 시스템은 과거보다 훨씬 안전해졌고 잘못된 결과를 차단할 수 있는 연구 플랫폼에
가까워졌다. 다만 `좋은 과거 성과를 찾는 시스템`에서 `미래에도 재현되는 전략을 검증하는
시스템`으로 전환하는 작업은 아직 끝나지 않았다. 우선순위는 새로운 전략 추가가 아니라
PIT 입력 증거, 실행 엔진 단일화, 비중복 잠금 표본, 다중검정 보정이다.
