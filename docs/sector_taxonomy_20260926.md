# 한국 주식 다중 분류 체계

## 목적

종목을 하나의 `sector_mid`에 강제로 넣지 않는다. 같은 종목에 업종, 시장 테마,
밸류체인 위치, 생산 공정, 핵심 소재·제품, 실질 경쟁군을 동시에 붙이고 모든 값에
출처, 관측일, 근거, 신뢰도와 판정 상태를 보존한다.

## 분류 축

| 축 | 의미 | 예시 |
|---|---|---|
| industry | 사업의 상위 업종 | 반도체, 전기/전자 |
| market_segment | 지수·규모·시장 구분 | KOSDAQ SMALL, 코스닥 벤처기업 |
| theme | 시장에서 함께 거래되는 테마 | 반도체_생산, 반도체_전공정소재 |
| value_chain | 가치사슬에서 맡는 역할 | 설계·팹리스, 파운드리·IDM, EMS·모듈 조립 |
| process | 실제 생산 공정 | 전공정 장비, 후공정 패키징·조립, 테스트·검사 |
| material | 공급 소재·부품 | 웨이퍼·기판, 케미칼·가스·소재 |
| peer_group | 제품·고객·공정이 겹치는 비교군 | OLED·스마트기기 PBA/FPBA 제조사 |

업종과 테마는 다르다. 업종은 사업의 구조적 분류이고, 테마는 시장이 특정 시점에
묶어 보는 관측 분류다. 경쟁군은 같은 업종이라는 이유만으로 만들지 않고 제품,
생산 공정, 고객 산업과 매출 구성의 겹침을 근거로 만든다.

## 원천과 역할

1. **기존 `stock_universe`**: 전 종목 기준선을 제공한다. 과거 여러 제공자가 섞였을
   수 있으므로 `universe_legacy`로 표시하고 정답으로 간주하지 않는다.
2. **StockEasy**: 공개 화면이 사용하는
   `https://stockeasy.intellio.kr/stockdata/api/v1/valuation/data`에서 대분류·중분류를
   관측한다. 제공자 분류를 그대로 보존하며 내부 분류를 덮어쓰지 않는다.
3. **Kiwoom REST**: 공식 API 가이드의 `ka10101`(업종코드), `ka20002`(업종 구성종목),
   `ka90001`(테마그룹), `ka90002`(테마 구성종목)를 사용한다. 지수·규모 구분은
   `market_segment`, 실제 업종은 `industry`, 테마는 `theme`로 분리한다.
4. **DART 제품 매출**: `company_product_mix` 최신 연도의 제품명과 매출 비중을
   밸류체인·공정·경쟁군의 근거로 사용한다.
5. **내부 규칙/검토**: 규칙 결과는 `inferred`, 사람이 제품 근거를 확인한 경쟁군은
   `verified`로 표시한다. 규칙 버전은 노드와 스냅샷에 남긴다.

## 판정 상태

| 상태 | 의미 |
|---|---|
| verified | 제품·매출·공정 근거를 검토한 내부 분류 |
| observed | 외부 제공자가 직접 반환한 분류 |
| inferred | 제품명·사업 설명에 버전이 있는 규칙을 적용한 후보 |
| legacy | 기존 필드에서 옮긴 비교 기준선 |

`confidence`는 같은 상태 안에서 우선순위를 돕는 값일 뿐 서로 다른 제공자의 진위를
자동 결정하지 않는다. 제공자 사이 분류가 다르면 API와 화면에서 불일치로 표시한다.

## 데이터 모델

- `sector_taxonomy_nodes`: 출처별 계층 노드. `taxonomy`, `dimension`, 부모, 원천 코드,
  설명, 원천 URL, 버전을 보존한다.
- `stock_sector_membership_v2`: 종목-노드 다대다 관계. 출처, 스냅샷 날짜, 신뢰도,
  상태와 JSON 근거를 보존한다.
- `sector_taxonomy_source_runs`: 수집 성공/실패, 행 수, 해시와 오류를 기록한다.
- 과거 스냅샷은 삭제하지 않는다. 조회는 출처별 최신 **성공** 스냅샷만 사용한다.
- 같은 날짜 재실행은 해당 출처·날짜만 교체해 멱등성을 유지한다.

## 초기 검증 경쟁군

`OLED·스마트기기 PBA/FPBA 제조사`에는 다음 세 종목을 검증 상태로 등록했다.

| 종목 | 근거 |
|---|---|
| 제이엠티(094970) | 2025 DART 제품 매출: PBA 32.27%, FPBA 25.83% |
| 디케이티(290550) | 스마트폰 65.04%, 전장 25.19%; 연성회로·모듈 조립 비교축 |
| 한국컴퓨터(054040) | OLED-PBA 59.19%, QD/LCD 모듈 부품 32.84% |

세 종목에는 `전자부품 → EMS·모듈 조립 → PBA·FPBA·모듈 조립 → 경쟁군` 경로를
함께 부여했다. 이 그룹은 주가 동조성만으로 만든 테마가 아니라 제품·공정 비교군이다.

## 운영과 품질 규칙

- `scripts/rebuild_sector_taxonomy.py`가 전체 스냅샷을 갱신한다.
- 스케줄러 `종목다중분류` 잡이 매일 20:10 실행한다.
- StockEasy는 2,000종목 미만으로 급락하거나 응답 구조가 바뀌면 실패 처리한다.
- 외부 수집 실패 스냅샷은 최신 조회에 승격하지 않는다.
- 화면의 원천 날짜가 오래되면 경고색으로 표시한다.
- 내부 규칙 확대 시 거짓 양성을 표본 검토하고 규칙 버전을 올린다.
- 경쟁군은 DART 제품 구성, 사업보고서 설명, 고객/공정 축을 확인한 뒤 `verified`로
  승격한다. 자동 유사도만으로 `verified`를 부여하지 않는다.
