> 작성일: 2026-04-26 | 전략 코드: `v9` | 파일: `backtest.py → _is_buy_signal_v9 / _check_sell_v9`

## 1. 전략 개요

**텐배거(Tenbagger)**: 매수 후 3~5년 내에 주가가 10배 이상 상승한 종목.

이 전략은 2019~2026년 국내 시장에서 실제 10배 이상 상승한 종목들의 공통 패턴을 분석한 결과를 토대로 설계됩니다. 단기 스윙이 아닌 **중기 모멘텀 포착**에 초점을 맞춥니다.

---

## 2. 2019~2026 텐배거 DNA 분석

### 2.1 공통 특성 (10배 이상 상승 종목 패턴)

| 특성 | 내용 | 대표 사례 |
|------|------|-----------|
| **메가트렌드 부합** | EV/AI/방산/K-수출/바이오/원전/로봇 | 에코프로비엠(배터리), 한화에어로스페이스(방산), 리가켐바이오(ADC) |
| **구조적 EPS 턴어라운드** | 수년간 적자 → 흑자 전환 or 매출 고성장 | HLB(임상 성공), 알테오젠(기술이전) |
| **독점적 포지션** | 글로벌 경쟁사 대비 원가·기술 우위 | 에코프로비엠(전구체 수직계열화) |
| **소형·중형주** | 시총 1.5조 이하 (상승 여력) | 초기 에코프로(시총 수백억) |
| **거래량 폭발** | 신고가 돌파 직전 또는 돌파 시 거래량 급증 | 2차전지 테마 폭등기 |
| **52주 신고가 권역** | 매수 시점에 이미 전고점 88% 이상 | "신고가가 신고가를 부른다" |

### 2.2 가짜 펌핑 함정 (Anti-patterns)

| 유형 | 특징 | 구별법 |
|------|------|--------|
| **CB/BW 폭탄** | 전환사채·신주인수권부 과잉 발행 | 부채비율 200%+ / 전환청구 예정일 가격 하락 |
| **내러티브 only** | 테마는 맞지만 매출·이익 없음 | 영업이익 지속 적자 + 매출 정체 |
| **데드캣 바운스** | 대세 하락 중 일시 반등 | MA200 하방 + 52주 고가 50% 미만 |
| **단기 투기** | 거래량 급증 후 하루만에 소멸 | 당일 거래량만 폭발, 다음날 정상화 |

## 3. 정량적 매수 조건 (`_is_buy_signal_v9`)

```
조건 1 (시장 필터):
  KOSPI 종목 → KOSPI regime ≥ 2 (중립 또는 강세)
  KOSDAQ 종목 → KOSDAQ MA60 위 (상승 추세)

조건 2 (추세 확립):
  현재가 > MA200 (200일 이동평균 위)

조건 3 (신고가 권역):
  현재가 ≥ 250일 고가 × 0.88 (52주 고가의 88% 이상)

조건 4 (거래량 폭발):
  당일 거래량 > 60일 평균 거래량 × 3.0배

조건 5 (실적 필터):
  영업이익 > 0 (흑자)
  OR 매출 YoY +30% 이상 (고성장)

조건 6 (규모 필터):
  시총 ≤ 1,500,000,000,000 원 (1.5조 이하)
  (stock_universe.market_cap 기준)
```

**모든 조건을 동시에 충족해야 매수 신호 발생.**

## 4. 매도 로직 (`_check_sell_v9`)

"수익은 길게, 손실은 짧게" 원칙을 따릅니다.

| 청산 유형 | 조건 | 비고 |
|-----------|------|------|
| **Time Stop** | 5일 보유 + 수익률 ≤ 0 | 조기 실패 확인 |
| **하드 손절** | -8% | 최대 손실 제한 |
| **Scale-out** | +30% 도달 시 절반 익절 | 타 전략보다 늦게 설정 (수익 극대화) |
| **잔여분 MA20** | Scale-out 후 MA20 이탈 + 수익 +15% 이상 | 잔여분 추적 관리 |
| **잔여분 손절** | Scale-out 후 +10% 선 이탈 | 잔여분 최소 수익 보호 |
| **추적손절** | 수익 +15% 이상 후 고점 대비 -20% | 큰 수익 보호 |
| **MA20 추적** | 수익 +15% 이상 후 MA20 이탈 | 진행 중 트렌드 이탈 감지 |

## 5. AI 검증 모듈 (`tenbagger_ai.py`)

### 5.1 Claude API 통합

`ANTHROPIC_API_KEY` 환경변수가 설정된 경우 `claude-sonnet-4-6` 모델을 사용하여 다음을 분석:

1. **메가트렌드 부합**: EV/배터리/AI/반도체/방산/K-수출/바이오/원전/로봇/우주항공
2. **가짜 리스크**: CB/BW 과잉(부채비율), 실적 없는 테마, 데드캣 바운스
3. **구조적 턴어라운드**: 영업이익 흑자 OR 매출 YoY 30%+ 
4. **독점적 포지션**: 글로벌 점유율, 특허, 고객 고착도

### 5.2 응답 형식

```json
{
  "verdict":         "strong_buy | buy | watch | avoid",
  "tenbagger_score": 0~100,
  "is_megatrend":    true/false,
  "is_fake_risk":    true/false,
  "reasons":         ["긍정 근거1", "긍정 근거2"],
  "warnings":        ["위험 요소1", "위험 요소2"],
  "ai_summary":      "한 문장 종합 판단",
  "source":          "claude_api | quant_fallback"
}
```

### 5.3 정량 폴백 (API 키 없을 때)

|------|------|
| 메가트렌드 섹터 | +20점 |
| MA200 상방 | +15점 |
| 52주 고가 88% 이상 | +15점 |
| 거래량 3배 이상 | +10점 |
| 영업이익 흑자 | +10점 |

## 6. API 엔드포인트

```
POST /api/tenbagger/analyze/{code}
  payload: { date, force_refresh }
  → 단일 종목 AI 분석

POST /api/tenbagger/scan
  payload: { scope, min_score, limit, date }
  scope: "watchlist" | "universe" | "all"
  → 일괄 스캔 + 캐시 업데이트

GET  /api/tenbagger/candidates
  → 최근 스캔 결과 반환

GET  /api/tenbagger/watchlist-quick
  → 관심종목 정량 빠른 스캔 (API 미사용)
```

## 8. 주의사항

1. **역발상 투자 아님**: 텐배거는 이미 상승 추세에서 추가 상승을 포착하는 전략입니다.
2. **소형주 리스크**: 시총 1.5조 이하는 유동성 리스크가 있습니다. 실제 매매 시 충분한 유동성 확인 필요.
3. **AI 분석 한계**: Claude API는 DB 데이터와 공개 정보만 참조합니다. 내부 정보나 최신 공시는 반영되지 않을 수 있습니다.
4. **2022년 데이터**: 백테스트 시 2022년 이전 데이터는 `collect_krx_history.py`로 별도 수집 필요.
5. **CB/BW 필터**: 현재 정량 필터에는 CB/BW 부채 필터가 포함되지 않습니다. AI 검증 단계에서 Claude가 이를 지적합니다.
