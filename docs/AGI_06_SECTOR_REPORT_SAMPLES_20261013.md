## 1. 업종별 정형 폼 — 공통부 + 업종 고유부

**공통부**(모든 업종 동일): 투자의견·목표가·현재가·상승여력, Key Data(시총·발행주식수·
외국인지분율·52주 범위·주요주주), 분기 실적 테이블(매출·영업이익·순이익, QoQ/YoY),
핵심 이슈 3~4줄, 리스크.

**업종 고유부**(리포트 4건을 비교해서 뽑음):

| 업종 | 고유 섹션 | 우리 DB 소스 |
|---|---|---|
| 반도체 제조/장비 | 법인·사업부별 매출 분해, 가동률, 컨센서스 대비 서프라이즈 | `company_product_mix`, `financial_data`(CFS/OFS 비교로 법인 분해 근사) |
| 금융지주 | 자본비율(CET1 등), 비은행 자회사 기여도, 자본정책(배당·M&A) 이벤트 | `dart_disclosures`(지분·M&A 공시), `financial_data` |
| 의료기기/바이오 | 규제 승인 현황(FDA/식약처 등), 반복매출 비중(소모품/서비스), 해외 매출 비중, Peer PER/PBR | `dart_disclosures`(인허가 공시), `company_product_mix`, `stock_universe`(PER/PBR) |
| 수주산업(조선/건설/기계) | 수주잔고(물량 연수), 수주가/단가 추이, 가동 캐파, 환율·원자재 민감도 | `order_backlog`, `dart_backlog_quarterly` |
| 렌탈·임대/일반 산업재(없을 때 기본형) | 부문별(렌탈/유통 등) 매출 비중, 자산 활용률 성격 지표 | `company_product_mix`, `segment_revenue` |

**투자정보**: 시가총액 8,423억원 · PBR 5.1배 · ROE -20.8%(`stock_universe`, 아직 적자 구간)

**업종 고유 체크(의료기기 리포트가 강조한 항목과 대조)**:
- 규제 승인: 참고 리포트는 "하반기 아티스테이플러·리브스캠·스타크 FDA 승인 준비 중"이라
  언급 — 우리 DB(`dart_disclosures`)에는 최근 공시가 IR개최·반기보고서·지분보고뿐이라

- 매출은 성장(+21.9% QoQ)하지만 영업손실이 더 커짐 — 참고 리포트의 "소모품/반복매출
  비중 확대가 핵심 투자 포인트"라는 틀에서 보면, 지금 숫자만으로는 반복매출 비중을
  분해할 세그먼트 데이터가 없다(제품이 ArtiSential 하나로 집중돼 있어 제품 믹스로는
  반복/비반복 구분이 안 됨 — 공시 본문 파싱이 필요, AGI-04 영역).

안 됨 — `dart_disclosures`에 처분·지분법 관련 공시가 있는지 수동 대조 필요).

## 5. 이번 작업에서 새로 확인한 것(템플릿 설계에 반영할 점)

1. **반도체·금융은 템플릿이 잘 맞는다**(법인분해·CET1처럼 업종 고유 숫자가 DB에 가깝게 있음).
2. **의료기기는 "규제 승인 상태"가 핵심인데 국내 DART 공시만으로는 못 잡는다** — 해외
   규제기관(FDA 등) 승인은 별도 추적이 필요(뉴스/애널리스트 리포트 의존도가 더 큼 →
   AGI-03 블로그/텔레그램 선택 수집이 의료기기 쪽에서 특히 유용할 것).
3. **복합 사업(렌탈 등)은 업종 템플릿이 따로 없다** — "부문 2개 이상이면 부문별로 쪼갠다"는
   범용 규칙으로 처리.
4. **영업이익과 순이익의 괴리는 모든 업종에서 공통으로 설명이 필요한 항목**이라 공통부로
   올려야 한다(지금 4번 섹션에서 수동으로 발견한 것 — 자동화하려면 일회성 항목 추출기가
   필요, AGI-04 범위).
