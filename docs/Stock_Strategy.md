## 0. 공동 검토 규칙 (모든 AI·사람 공통)

1. **한 항목 = 한 ID**(S01…, P1-1…). 새 발견은 §4 표에 ID를 이어 붙여 추가한다. 기존 항목의 설명을 지우지 말고, 반박·보완은 §9 검토 로그에 쓴다.
2. **상태값**: `open`(미검토) → `confirmed`(재현/측정으로 확인) → `planned` → `in-progress` → `done`(검증까지 끝남) / `rejected`(근거와 함께 기각).
3. **사실과 추정을 구분**한다. 측정한 값은 `[측정 YYYY-MM-DD]`, 코드로 확인한 것은 `[코드]`, 추정은 `[추정]`으로 표시한다. 재현 명령은 §10에 남긴다.
4. **"문제없음"은 값 대조로만** 판정한다(형태만 보고 정상 처리 금지). 대조 건수를 함께 적는다.
5. **보정된 기준선 이후에만 수익 개선을 주장**한다(`claude_handoff_strategy_code_findings_20260912.md` F01~F09 참조). 수익률이 낮아져도 결함 수정이면 실패가 아니다.
6. **임계값을 사람이 감으로 바꾸지 않는다.** 조건 완화·강화는 (a) 가설 (b) 비용 차감 백테스트 (c) 학습/검증 구간 분리 결과를 `signal_experiment_ledger`에 기록한 뒤에만 채택한다. 기각된 실험도 기록한다.
7. 코드 수정은 `runtime/`에서만, 서버 재시작은 `scripts/safe_restart_backend.sh`로만. 수정하면 `CLAUDE.md` 변경 이력(1~3문장)과 이 문서의 상태를 같이 갱신한다.
8. **동시 편집 충돌 방지**: 이 문서를 고칠 때는 §9에 `작업 중: <AI명> <시각>`을 먼저 적고, 끝나면 지운다.
9. 사용자 승인이 필요한 항목은 §8 "결정 대기"에만 모은다. 승인 없이 정의·기준을 바꾸지 않는다.

## 2. 질문 1에 대한 1차 답 — 577개는 무엇이고 왜 문제인가

### 2-1. "V1 577종목"의 정체 [코드]
- 화면 문구 `Logic v1 — 전체 N종목`은 `Screener.jsx`의 `comboLogic==='v1'` 배너이며, 전략 센터에서는 **V5 복합콤보(`v4` 키)**를 가리킨다. 전략 센터의 "V1 MA추세"(`v_trend`)와 이름만 같고 **다른 로직**이다. (→ S06 라벨 혼선)
- 데이터 원천은 `/api/signals/combo-candidates` — 추세·가치·재무 3개 스크리너 중 **2개 이상 동시 충족**한 종목 전부다. 점수 컷·순위 컷·개수 상한이 없다.

### 2-2. 지금 측정한 사실 [측정 2026-10-05]
| 스크리너 | 현재 통과 종목 수 |
|---|---:|
| `/api/signals/value-candidates` (가치) | **850** |
| `/api/signals/trend-candidates` (추세) | 4 |
| `/api/signals/fin-screener` (재무) | 0 |
| `/api/signals/combo-candidates` (콤보) | 0 (서버 캐시 미적재 상태 — 호출만으로는 계산을 시작하지 않고 빈 배열 반환) |

- 가치 조건만으로 850종목이다. 사용자가 본 577이라는 숫자는 **캐시 상태·시점에 따라 바뀌는 값**이라 지금은 재현되지 않는다. 재현이 선행되어야 한다 → S03.

### 2-3. 결론: "전략이 틀렸다"기보다 **"후보 풀 정의"와 "매수 선택 규칙"이 분리돼 있어 풀이 통제되지 않는다**
1. **[코드] 가치 조건이 OR로 느슨하다.** `calc_value_candidates`: `Graham 할인 ≥15%` **또는** `(PBR<1 AND 0<PER<15)`이면 통과. 한국 시장에서 PBR<1·PER<15는 흔한 구간이다 → 850종목 → 콤보 후보 폭증의 1차 원인 후보. (S02)
2. **[코드] 백테스트는 선택 규칙이 있는데 화면 추천에는 없다.** 백테스트는 `max_positions=10`, `max_new_per_month=8~10`, 시총 하한(300~1000억), 손절·익절을 쓴다. 화면의 스크리너 목록은 이런 상한·순위가 없는 "조건 충족 전체 집합"이다. 즉 **백테스트가 검증한 것은 "상위 월 10개"인데 화면은 "충족 전부"를 보여 준다.** (S01)
3. **[추정] 후보가 많은 전략은 신호 변별력이 낮다.** 전체의 25%가 통과하는 조건은 "선별"이 아니라 "시장 상태 필터"에 가깝다. 검증 방법은 §5 P2-2(후보 비율 vs 사후 초과수익) 참조.
4. **[측정] 위 전략들의 성과도 약하다.** 전략 레지스트리에서 V5(`v5`)·V2(`v2`)·V2 가치(`v1_value`)는 평균 −1.7~−4.7%, 모두 `retired`·`legacy`(검증 등급 미달). 퇴역 전략인데 화면에서는 선택·추천 가능하다. (S05)
