## 1. 전략 설계 철학

한국 주식시장은 세 가지 비가격 정보를 **선행지표**로 활용할 수 있다는 전제에서 출발합니다:

| 정보 | 선행 효과 | 데이터 공개 시점 |
|------|-----------|-----------------|
| 미국·일본·대만 동종 섹터 주가 | 한국 동종주 1일 선행 | 전일 종가 |
| HS 코드별 월간 수출 실적 | 해당 기업 분기 실적 1개월 선행 | 당월 말 +15일 |
| 고용보험 임직원 현황 | 기업 매출·물량 증가 선행 | 당월 말 +30일 |

이 세 가지를 기존 **추세(Minervini)·가치(Graham)** 지표와 통합하여 종합 점수로 매수 결정합니다.

## 2. 시장 국면 (KOSPI Regime) — Logic #5 계승

Logic #6는 Logic #5의 KOSPI 4단계 국면 분류를 그대로 계승합니다:

| 국면 | KOSPI 조건 | 매수 임계값 | 설명 |
|------|-----------|------------|------|
| **3 강세** | KOSPI > MA60 | 0.50 | 공격형, 낮은 진입 기준 |
| **2 중립** | MA120 < KOSPI ≤ MA60 | 0.55 | 균형형 |
| **1 약세** | MA200 < KOSPI ≤ MA120 | 0.62 | 방어형, 높은 기준 |
| **0 대하락** | KOSPI ≤ MA200 | **전면 금지** | 현금 보유 |

## 3. 5가지 팩터 상세

### 팩터 1: 기술적 모멘텀 (가중치 30%)

| 조건 | 점수 |
|------|------|
| 3중 정배열 (curr > MA60 > MA120) | +1.2 |
| 2중 정배열 (curr > MA60) | +0.8 |
| MA20 상방 | +0.3 |
| RSI 50~75 | +0.9 |
| RSI 40~50 | +0.4 |
| 거래량 ≥ 20일 평균×2배 | +0.9 |
| 거래량 ≥ 20일 평균×1.3배 | +0.5 |
| **최대** | **3.0** |

### 팩터 2: 해외 동조효과 (가중치 25%)

- **섹터 매핑**: 한국 종목의 `sector_large` → 해당 해외 종목 리스트
  ```
  반도체    → NVDA, AMD, AVGO, MU, ^SOX
  반도체장비 → AMAT, LRCX, KLAC, 8035.T
  2차전지   → TSLA, ALB
  전력장비  → ETN, VRT
  제약      → LLY, NVO
  바이오    → MRNA, ABBV
  방산      → LMT, NOC, RTX
  해운      → ZIM, STNG, SBLK
  에너지    → XOM, CVX
  소재      → FCX, RIO
  기타      → ^GSPC, ^IXIC (S&P500, NASDAQ)
  ```
- **계산**: 전일 종가 기준 1일·5일 평균 변동률
- **구성**: `섹터 스코어 × 0.7 + 글로벌지수(^GSPC,^IXIC) × 0.3`

| 평균 변동률 | 점수 |
|------------|------|
| ≥ +2.0% | 3.0 |
| +0.5% ~ +2.0% | 2.5 |
| -0.3% ~ +0.5% | 1.5 (neutral) |
| -1.5% ~ -0.3% | 1.0 |
| < -1.5% | 0.0 |

> **데이터 없으면 1.5 (neutral) 처리** — 해외 가격 미수집 종목도 다른 팩터로 판단 가능

### 팩터 3: 가치 품질 (가중치 20%)

| 조건 | 점수 |
|------|------|
| Graham 할인율 ≥ 25% | +1.5 |
| Graham 할인율 10~25% | +0.8 |
| PBR < 1.0 AND 0 < PER < 15 | +1.0 |
| PBR < 2.0 | +0.5 |
| RS(63일 상대강도) ≥ 10% | +0.5 |
| RS ≥ 3% | +0.2 |
| **최대** | **3.0** |

**공통 필수 조건**: 영업이익 > 0 (불황 생존 기업 필터)

### 팩터 4: HS 수출 모멘텀 (가중치 15%)

- **DB**: `hs_trade_lab/data/hs_trade_lab.db`
- **테이블**: `hs_code_company_map` × `trade_series_cache`
- **계산**: 최근 3개월 평균 수출액 vs 전년 동기 3개월 평균 YoY 증감율
- **데이터 공개 지연**: `period_ym` 마지막일 + 15일 이후 사용

| YoY 수출 증감 | 점수 |
|--------------|------|
| ≥ +30% | 3.0 |
| +10% ~ +30% | 2.5 |
| -5% ~ +10% | 1.5 (neutral) |
| -20% ~ -5% | 0.8 |
| < -20% | 0.0 |

> HS 코드 매핑 없는 종목: **1.5 (neutral)** — 불이익 없음

### 팩터 5: 고용 증가 (가중치 10%)

- **DB**: `employment_monitor/employment.db`
- **테이블**: `employment_company_monthly`
- **계산**: 최근 월 임직원 수 vs 12개월 전 YoY 증감율
- **데이터 공개 지연**: `ym` 마지막일 + 30일 이후 사용

| YoY 임직원 증감 | 점수 |
|----------------|------|
| ≥ +10% | 3.0 |
| +3% ~ +10% | 2.5 |
| -1% ~ +3% | 1.5 (neutral) |
| -5% ~ -1% | 0.8 |
| < -5% | 0.0 |

## 4. 종합 점수 계산

```
총점 = (기술 × 0.30 + 해외 × 0.25 + 가치 × 0.20 + HS × 0.15 + 고용 × 0.10) / 3.0
     = 0.0 ~ 1.0 스케일
```

**예시 (반도체 종목, 강세장)**:
- 기술 2.5 × 0.30 = 0.75
- 해외(NVDA+SOX 상승) 3.0 × 0.25 = 0.75
- 가치 1.8 × 0.20 = 0.36
- HS(수출+15%) 2.5 × 0.15 = 0.375
- 고용(+5%) 2.5 × 0.10 = 0.25
- **합계 = 2.485 / 3.0 = 0.828** → 강세 임계값 0.50 초과 → **매수**

## 6. Logic #5 대비 개선점

| 항목 | Logic #5 (v6) | Logic #6 (v7) |
|------|-------------|-------------|
| 매수 기준 | 이진 (Yes/No) | 가중 점수제 (0~1.0) |
| 해외 동조 | ❌ 미반영 | ✅ 섹터별 25% 가중 |
| 수출 실적 | ❌ 미반영 | ✅ HS코드 15% 가중 |
| 고용 지표 | ❌ 미반영 | ✅ 임직원 10% 가중 |
| 데이터 없음 | 매수 불가 | neutral 처리 (0 불이익 없음) |
| 임계값 | 고정 Boolean | 국면별 유연 (0.50~0.62) |

## 7. 미래참조 방지 규칙

| 데이터 | 공개 시점 | 적용 규칙 |
|--------|-----------|---------|
| HS 수출 | 당월 말 +15일 | `period_ym ≤ (date - 15일)` |
| 고용 | 당월 말 +30일 | `ym ≤ (date - 30일)` |
| 분기 재무 | 분기 말 +45일 | `_release_date()` 동일 |
| 연간 재무 | 연말 +90일 | `_release_date()` 동일 |
| 해외 주가 | 전일 종가 | 1-day lag 적용 |
| 국내 주가 | 당일 종가 | 당일 시그널 → 당일 종가 집행 |
