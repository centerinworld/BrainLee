# 백테스트 시스템 독립 무결성 검토

## 결론

현재 전략센터 결과는 실전 주문 근거로 사용할 수 없다. 당일 가격 수집 범위는 정상권이지만,
기존 선택 런의 데이터 가용시점 증빙과 일부 상장구간·체결 계약이 불완전하다. 자동매매는 계속
비활성화하고 아래 게이트를 통과한 새 런만 승격해야 한다.

## 이번에 완료한 조치

- 폐기된 `/Applications/stock_dashboard` 심볼릭 링크를 제거하고 외장 런타임만 사용하도록 정리했다.
- 현재 유니버스 분모를 오염된 `stock_universe` 5,459행에서 기준일 유효 종목 마스터 2,713개로 교체했다.
- 당일 가격 범위는 거래 제한 25개를 제외한 2,688개 중 2,683개(99.81%)로 재산출했다.
- KRX 기준구간 이전 가격 이력을 버리던 마스터 재구축 오류를 수정하고 115개 과거 구간을 복원했다.
- 마스터 4,244행과 주식수 이력 94,939행을 PostgreSQL 백업 테이블에 보존했다.
- 전략 24곳뿐 아니라 가격·KIS·DART·텔레그램·ETF·신호 엔진과 백필 스크립트의
  `GLOB '[0-9]*'`도 정확한 6자리 숫자 검사로 교체해 `00088K` 같은 공급자 별칭의
  신규 유입 경로를 제거했다. HS 코드는 가변 길이를 유지하면서 비숫자 문자를 차단한다.
- 시총 룩어헤드 감사를 단일 파일에서 43개 백테스트 파일 전체로 확대했다.
- 섹터 전략의 거래비용 시총을 현재값이 아닌 당시 발행주식수와 가격으로 계산하도록 수정했다.
- 가격, 생존편향, 기업행사, 데이터 가용시점 아티팩트가 없으면 검증 등급이 올라가지 않도록 fail-closed 처리했다.
- 실행기간별 가격 합계·거래량·가중 체크섬과 데이터 리비전 지문을 런 사양에 저장하도록 강화했다.
- 테스트 DB 경로를 무시하고 운영 PostgreSQL에 아티팩트를 기록하던 격리 오류를 수정했다.
- 재발 방지 검사를 `unittest`에 연결했으며 전체 96건, 엄격 공유 시뮬레이터 C3-C6,
  Python 컴파일 및 수정 파일 `git diff --check`를 통과했다.

## 남은 차단 항목

- 선택 전략 가격 무결성: 23/26 통과. `regime_adaptive`, `v_trend`, `v4`의 기존 런은 재실행 전까지 무효다.
- 데이터 가용시점: 156개 구간 중 24개 통과, 132개 실패. 재무·공시 입력 행 ID와 `available_at`을 신호마다 저장해야 한다.
- 정적 계약: P0 1건, P1 29건. `high_profit_compound`의 당일 종가 체결은 엄격 체결기로 이관하기 전까지 사용 금지다.
- 기업행사: 10,472건 중 자동 확정 2,575건, 검토 필요 5,388건이다. 미확정 이벤트를 지난 거래는 계속 차단한다.
- 전진검증: 완료 표본이 아직 없으며 17개 에피소드가 수집 중이다. 최소 90일·완료 30건 전에는 실전 승격하지 않는다.
