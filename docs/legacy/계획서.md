# 프로젝트 안티그래비티: 주식 분석 백엔드 시스템 구축 계획서

## 1. 시스템 아키텍처 개요
본 프로젝트는 macOS 환경에서 구동되는 주식 데이터(재무+시세) 처리 및 AI 분석 백엔드 서버(FastAPI) 구축을 목표로 한다. 외부 데이터 수집(DART, 주가/차트) 및 메신저 전송은 'OpenClaw'가 담당하며, 본 백엔드는 데이터를 정제, 분석, 저장, 재가공하는 '두뇌' 역할을 수행한다.

## 2. 전체 워크플로우 로직 (Interactive Flow)
1. **사용자 명령 (Telegram)**: 사용자가 텔레그램을 통해 종목명(예: "삼성전자 분석해줘")으로 분석 명령을 내림.
2. **명령 전달 (OpenClaw)**: OpenClaw가 백엔드의 대화형 API(`POST /api/commands/analyze/{stock_name}`)를 호출하여 명령 전달.
3. **데이터 수집 및 분석 (Backend)**:
   - **수집**: `data_collector`가 즉시 작동하여 DART(재무) 및 Yahoo Finance(5분 단위 시세)에서 최신 데이터 수집.
   - **분석**: `AIAnalyzer`가 수집된 정량 데이터를 바탕으로 입체 분석 리포트 생성.
4. **결과 전달 (Backend -> OpenClaw)**: 생성된 최종 리포트를 OpenClaw가 API를 통해 수신.
5. **최종 답변 (Telegram)**: OpenClaw가 분석 결과를 요약하여 사용자의 텔레그램으로 전송.

## 3. 단계별 실행 계획 (Phase-by-Phase)

### Phase 1: 기반 환경 및 통합 DB 스키마 설계
1. `requirements.txt` 세팅 (FastAPI, SQLAlchemy, pandas 등 시계열 데이터 처리 라이브러리 포함).
2. `models.py` 확장 작성:
   - `financial_data`: DART 기반 재무 수치 (분기/연간).
   - `price_history`: OHLCV 및 일자별 주가 시계열 데이터.
   - `sector_info`: 섹터별 지수 및 소속 종목 맵핑 테이블.
   - `ai_analysis_reports`: 최종 분석 코멘트.

### Phase 2: 데이터 수집 및 Ingestion API 구축
1. `main.py`에 수집 엔드포인트 생성 (`POST /api/ingest/...`).
2. **[UPDATE]** `data_collector.py`: 실시간(5분 마다) 주량 및 일일(1회) 재무 데이터를 자동으로 수집하여 백엔드로 쏘아주는 자동화 엔진 구축.

### Phase 3: 주가/차트 데이터 재가공 및 복합 스크리닝 엔진
1. `processor.py` 로직 추가: 차트용 JSON 배열 포맷 변환 및 지표 계산.
2. `screener.py` 복합 스크리닝 구현: 재무 + 주가 모멘텀 복합 필터링.

### Phase 4: AI 분석 모듈 결합
1. `ai_analyzer.py` 작성: 재무 + 시세 데이터를 결합한 입체 프롬프트 기반 분석.

### Phase 5: Dashboard & OpenClaw Output API 구축
1. 대시보드 시각화 및 OpenClaw 연동용 반환 API 구축.

### Phase 6: 프리미엄 프론트엔드 대시보드 구축
1. **기술 스택**: Vite + React + Vanilla CSS + Recharts.
2. **디자인 테마**: 다크 모드, 글래스모피즘(Glassmorphism) 적용.

### Phase 7: 대화형 명령 API 및 종목명 매칭 (Interactive API)
1. 사용자가 종목명으로 명령을 내릴 수 있도록 '종목명 <-> 종목코드' 변환 매퍼 구축.
2. `POST /api/commands/analyze/{stock_name}`: 분석 명령 수신 및 즉시 수집/분석 트리거 구현.
3. OpenClaw를 '텔레그램 전송기'로 활용하여 양방향 소통 채널 완성.
