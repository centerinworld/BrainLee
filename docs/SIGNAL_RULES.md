# 매매 신호 규칙 — 정본 (2026-10-05, Claude)

> 계좌현황(추세추종 신호·매도시그널), 국내 종목 차트시그널 종합 판정, 매수후보 진입 신호는 **모두 이 문서의 규칙 하나**를 쓴다.
> 코드는 `trend_rules.py` 한 곳. 화면마다 따로 규칙을 만들지 말 것(예전엔 화면마다 달라 같은 종목이 '익절고려'·'바닥 반등'·'매수'로 엇갈렸다).
> 숫자 데이터(재무·가격 등)의 정본은 [FINANCIAL_STATEMENTS.md](FINANCIAL_STATEMENTS.md). 이 문서는 신호 판단만.

## 0. 원칙 (사용자 지시 2026-10-05)
- 규칙 출처 = 백테스트로 채택한 **모멘텀Easy**(`backtest_strategies/se_momentum.py`)·**피크Easy**(`backtest_strategies/peak_easy.py`) 진입·매도 규칙. 실제 스탁이지 편출내역으로 교정된 값.
- **추세가 살아 있는 동안 PER·PBR·ROE 같은 가치 지표만으로 매도 신호를 내지 않는다.** 매도는 추세 이탈·추적손절·기준가 이탈에서만("진짜 추세가 전환해야 매도").
- 반등 중인 종목에 '매도'라고 쓰지 않는다 → '반등 관찰 + 매도 기준가'.
- 신호는 기계적 규칙 결과이며 투자 자문이 아니다(화면에도 명시).
- 원주가(price_history) 기준이라 무상증자·분할일에 가짜 급락이 생긴다 → `action_factors()`로 `corporate_action_events`의 factor_confirmed 이벤트 중 **그날 실제 가격 비율이 계수의 0.6~1.4배인 것만** 보정(중복 등록 이벤트 제외, 예 494120 2026-08-21).

## 1. 추세 국면 `assess_trend(closes)` — 모든 신호의 기반
| 국면 | 조건 | 의미 |
|---|---|---|
| up 상승 추세 | 20일선 ≥ 60일선, 현재가 ≥ 20일선, 5일선 ≥ 20일선×0.96 | 매도 조건 없음 |
| pullback 상승 추세 속 조정 | 20일선 ≥ 60일선, 현재가 < 20일선(5일선은 아직 20일선×0.96 위) | 추세 유효 |
| weakening 추세 약화 | 20일선 ≥ 60일선, 5일선 < 20일선×0.96 | 모멘텀Easy 매도 조건 |
| rebound 하락 추세 속 반등 | 20일선 < 60일선, 현재가 > 20일선 | 전환 미확인(골든크로스 전) |
| down 하락 추세 | 20일선 < 60일선, 현재가 ≤ 20일선 | 피크Easy 매도 조건 |
가격 60일 미만은 판단 불가.

## 2. 계좌현황
**추세추종 신호** (`routes/portfolio.py`): up → 가치 점수 ≥ 3이면 추가매수, 아니면 보유유지(가치 부담은 참고 문구만) · pullback → 보유유지 · rebound → 반등시도 · weakening → 추세약화 · down → 하락추세. 작은 배지 추±N(정배열 정도, 참고)·가±N(PBR·PER·ROE·ROA 점수, 추가매수 판단에만).

**매도시그널(기준가)** `exit_signal()`:
| 상태 | 조건 | 매도 기준가 |
|---|---|---|
| 보유 | up/pullback | 가격 기준가 = 추적손절가 고점×0.80(평단 대비 +5% 초과일 때만, 고점 = 매수일 이후 또는 매수일 없으면 현재 상승 추세 시작(20일선>60일선 교차) 이후)과 손절가 평단×0.92(손실 −8% 이내일 때만) 중 높은 값. 추세 이탈은 가격이 아니라 **5일선 < 20일선×0.96** 조건(원 전략과 같음, 2026-10-05 수정 전엔 현재가로 비교해 하루 급락에도 매도가 났음). 둘 다 해당 없으면 기준가 없이 추세 조건만 표시 |
| 반등 관찰 | rebound | 최근 20거래일 종가 저점(깨면 반등 실패 → 매도) |
| 매도 | 현재가 < 기준가, 또는 weakening/down | 사유 표시 |
평단 대비 −8%를 이미 넘긴 종목은 '손절가 이미 하회'를 안내만 하고 판단은 지금부터의 추세로 한다. 고점 대비 하락률은 추적손절이 작동하는 경우만 표시(1년 고점 대비 −77% 오표시 수정).

## 3. 국내 종목 차트시그널 (`routes/extra_signals.py` /api/extra-signals/chart)
- 큰 판정 = 추세 국면(1절): 🟢 상승 추세 — 매도 조건 없음 / 🟡 상승 추세 속 조정 / 🟠 추세 약화 / 🟡 하락 추세 속 반등 시도 / 🔴 하락 추세. 추세 섹션 제목도 같은 국면.
- 단기 추세(5>10일선)·주봉 저점 상승·캔들 반전 3요소는 '단기 타이밍(상승 신호 n/3 · 하락 신호 n/3)' 보조로만.
- 문구는 국면에 맞춘다(상승 추세에서 '바닥 다지기'·'바닥권'·'반등' 금지).

## 4. 매수후보 진입 (`routes/buy_candidates.py`, `entry_signal()`)
| 신호 | 조건 |
|---|---|
| 피크Easy 진입 | up/pullback + 현재가 ≥ 52주 고점×0.995 + 현재가 > 20일선 + 5일 평균 거래량 > 20일 평균×1.3 |
| 모멘텀Easy 진입 | up/pullback + 5일선 > 20일선 + 현재가 ≥ 20일선×0.97 + 기관 또는 외국인 5일 순매수 |
| 대기 | up/pullback, 위 조건 미충족(부족 조건 표시) |
| 반등 대기 | rebound |
| 진입불가 | weakening(추세 약화) / down(하락 추세) |
원 전략의 '주도 섹터 상위'·'KOSPI 대비 60일 상대강도' 조건은 이 화면에 데이터가 없어 확인하지 않는다(화면에 명시).

## 5. 원 전략(백테스트)과 다른 점 — 이 조합 자체는 백테스트하지 않았다
개별 숫자(0.96, 0.80, 0.92, 0.995, 1.3, 0.97)는 두 원 전략의 채택값과 같지만, **보유 종목에 두 전략을 합쳐 적용하는 방식은 백테스트한 적이 없다.** 차이:
1. **매도 조건 합집합**: 추세 약화(모멘텀Easy: 5일선 < 20일선×0.96)와 하락 추세(피크Easy: 20일선 < 60일선)를 둘 다 매도로 쓴다. 원 전략은 각각 한쪽만 쓴다.
2. **손절 −8%**: 원 전략은 넘는 즉시 매도. 이 화면은 **이미 −8%를 넘긴 채 보유 중인 종목에는 손절을 적용하지 않고 지금부터의 추세로 판단**한다(사용자 원칙 '반등 중에 매도 표시하지 말 것', 2026-10-05). 새로 −8%를 넘는 순간은 손절가로 매도 표시된다.
3. **추적손절**: 모멘텀Easy −20%(고점×0.80)만 판정에 쓴다. 피크Easy −25%(고점×0.75, `TRAIL_PEAK`)는 기준선 목록에 '(참고)'로만 표시한다.
4. **반등 관찰(20일 종가 저점)**: 원 전략에 없는 이 화면 고유 규칙. 원 전략(피크Easy)이면 20일선 < 60일선 상태라 이미 매도.
5. **매수후보 진입**: 주도 섹터 순위·KOSPI 대비 상대강도 조건 생략(4절). 피크Easy 진입은 원 전략처럼 **252거래일 이상 이력이 있을 때만**(신규 상장의 짧은 이력 '신고가' 제외, 2026-10-05 수정).
6. 무상증자 보정(0절)과 매수일 미기록 시 고점 기준(현재 추세 시작 이후)도 원 전략 엔진과 다르다.
→ **조합 백테스트(2026-10-05, `scripts/review/backtest_portfolio_rules_20261005.py`, 결과 `research_outputs/signal_rules_backtest_20261005.json`)**: 모멘텀Easy 진입 동일, 2020-03-01~2026-09-30 한 기간. 원 전략 매도(run `d695aef1`) 총 −37.88%·연 −6.97%·승률 35.6%·1,233건 vs 계좌현황 규칙(`ee182778`, 엔진 옵션 `exit_mode="portfolio_rules"`) 총 +30.26%·연 +4.10%·승률 27.25%·767건. **한 기간뿐이라 일반화 금지** — 다기간(6기간) 검증 필요. 또 원 전략의 이 기간 결과가 엔진 주석의 과거 수치(+45~54%)와 크게 달라 엔진 설정 변화 확인이 먼저다 — 실행 시점에 다른 세션의 미커밋 변경(재무 공시일 기준 시점 수정, `fin_disclosure_dates`)이 엔진에 들어 있었다.

## 6. 바꿀 때
- 숫자는 원 전략 채택값 — 바꾸려면 백테스트 재검증과 사용자 승인 후 이 문서 변경 이력에 기록. 5절의 차이를 늘리거나 줄일 때도 같다.
- 화면 설명(계좌현황 '📏 신호 판단 기준', 매수후보 범례 아래 '진입 기준', 차트시그널 note)은 이 문서와 같이 고친다.
