# 반도체 섹터 페이지 원칙

- 이 페이지의 목적은 실적이 개선되거나 우상향하는 반도체 기업을 사전에 탐지하는 것이다.
- `<반도체 섹터>` 메뉴는 기존 iframe/독립 페이지를 사용하지 않고 앱 내부 전용 페이지로 유지한다.
- 전체 디자인은 `시장 Radar`와 동일한 어두운 패널, 민트 포인트, 조밀한 테이블 흐름을 따른다.
- 탭 구조는 `반도체 종합현황`, `전종목`, `YoY 실적`, `QoQ 실적`을 기본으로 한다.
- `반도체 종합현황`은 Lv1별 종목 수, 상승 종목 수, 상승률, PSR 평균, 기준일 대비 변동률을 보여준다.
- `전종목`은 기업명, Lv1, Lv2, 고객, 주요업, 현재가, 변동률, 시총, PBR, PER, TTM, PSR, 기준일별 가격/수익률을 빠짐없이 표시한다.
- Lv1/Lv2 값이 없는 경우 공란으로 둔다.
- 주요업 설명은 종목명 또는 주요업 셀 hover tooltip/title로 확인 가능해야 한다.
- 기준일은 3개를 기본으로 하며 사용자가 수정할 수 있어야 한다.
- 기준일 대비 수익률은 현재가와 기준일 가격을 비교해 산출한다.
- 상승 값은 붉은 계열, 하락 값은 푸른 계열 음영과 텍스트로 표시한다.
- `전종목` 탭은 Lv1별로 별도 테이블을 나누어 표시한다.
- `YoY 실적`과 `QoQ 실적`은 엑셀의 매출/이익 행 구조를 유지하고 최신 개선률을 강조한다.
- 관련 수정은 가능한 한 `<반도체 섹터>` 페이지와 그 페이지 전용 데이터 로직에 한정한다.
