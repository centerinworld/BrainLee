## 실행 계획

2. 읽기 전용 REPEATABLE READ 트랜잭션에서 전체 저장 시세의 키/OHLCV 결측, 비유한값, 음수, OHLC 관계, 날짜 형식·미래 날짜 후보, 중복, 수집시각 결측을 검사한다.
3. Gemini 근거 수집 → Qwen 단순 전처리 → DeepSeek 그 전처리 대조 → Claude 독립 검증·보강. 실제 실패는 미충족으로 남기며 다른 모델을 해당 모델로 표시하지 않는다.
4. Codex가 SQL·실측·외부 의견을 대조하고 검수 증거, 제한, 다음 과업을 기록한다. 목표 상태를 완료로 바꾸지 않는다.

## 목표 수용 기준
전체 데이터셋·테이블/뷰·수집기·사용 화면·기간·종목·원천 버전의 목록과 책임 범위 100%를 확정한다. 이번 402개 public 테이블/뷰 목록은 출발점이며 모든 테이블이 수집 원천이라는 뜻은 아니다.

- 결측: 상장/상폐·거래정지·거래소 휴일·시차·원천 제공 범위를 반영한 기대 행/필수 필드와 대조한다. 미수집·해당 없음·미공개를 구별하고 임의 0 치환을 금지한다. 설명되지 않은 누락 0건.
- 중복: 데이터셋별 의미상 키와 원천 개정 버전을 명세한다. 원천 버전 보존과 현재 유효행 유일성을 분리하며 의미상 중복·충돌 0건.
- 단위: 원문 값·통화·배율·주식수/금액·수정/비수정 주가·회계 연결/별도·누적/단일분기·변환식과 버전을 보존한다. 검증 허용오차는 원천 정밀도로 정의하고 설명되지 않은 불일치 0건.
- 미래참조: 관측대상 시각, 원문 공개시각, 시스템 수신시각, 유효시각, 개정 버전을 분리한다. 시뮬레이션 시점에 이용 가능했던 자료만 조인하며 위반 0건. 미래 일정·전망은 종류 및 발표시각으로 구분한다.
- 배당/분할: 발표·배당락·기준·지급·효력 날짜, 비율·금액·통화와 취소/정정 이력을 검증한다. 수정주가와 원주가의 일관성·조정계수 이중 적용도 확인한다.
- 예외/격리/미검증을 통과로 집계하지 않는다. 모든 미해결 항목 0건 및 외부 보강 수용/기각 근거, 5단계 증거 충족이 있어야 후속 승인 주체가 수용 여부를 판단할 수 있다. 격리만으로 전체 수집 데이터 무결점을 주장하지 않는다.
- 새 수집·정정 시 동일 게이트를 재실행한다. 최초 인증 범위와 이후 지속 감시를 구분한다.

- 현재 단위는 모든 자산 코드의 저장 일봉을 포함하며 일단 (stock_code, date의 앞 10자리)를 중복 후보 키로 가정한다. 자산·시장·세션별 grain은 후속 확정한다.
- 한국시각 미래 날짜 검사는 후보 탐지다. 해외 시차, 당일 장전 생성, 전망·예정 일정, 실제 공개시각을 따로 검증한다.
- 원천 가격과 단위 대조, 기대 거래일 누락, 재무·배당/분할·캘린더 전수 검사는 이번 범위 밖이다.
- 결과 요약과 스크립트 해시는 보존하지만 전체 DB를 영구 동결하지 않았다. 트랜잭션 종료 후 동일 snapshot ID를 재사용할 수 없으므로 과거 동일 데이터 재현에는 별도 버전 스냅샷이 필요하다.

## Claude 의견에 대한 Codex 검토
- 채택: Qwen JSON 절단은 형식 실패다. 최초 원문을 보존했고 재시도도 실패했으므로 유효한 전처리 결과로 승격하지 않았다.
- 채택: OHLC 위반과 0원 집합은 교집합을 확인하기 전 합산하거나 빼지 않는다. 다음 과업에서 원인별 분해한다.
- 채택: trade_amount 및 수급 금액 필드 검사는 추가해야 한다. 이번 검사는 OHLCV 한정이다. 순매수 음수는 정상 가능하므로 가격 음수 규칙을 적용하지 않는다.
- 채택: 모델 검토 입력에는 anomaly_samples가 빠졌다. 실제 DB 증거 파일에는 30개 사례가 존재하지만 Claude는 이를 검토하지 못했다. 제공된 증거의 범위를 명확히 기록한다.
- 부분 채택: KST 04:41에 당일 날짜 행이 있다는 것은 시장/세션별 확인 후보다. 혼합 자산 테이블에서 당일 행 자체를 오류로 단정하거나 future_date 조건을 일괄 >=로 바꾸지는 않는다.
- 기각: Qwen이 심각도 평가를 하지 않았다는 비판은 사용자의 제한 역할과 충돌한다. Qwen은 판단하지 않는 것이 맞으며 심각도·검사 설계는 Codex/Claude가 담당한다.
- 미채택: text 날짜가 인덱스 효율을 저하시킨다는 주장은 실행계획 증거가 없다. 날짜 유효성·타입 계약 검토만 후속 항목으로 남긴다.

현재 필요한 것은 데이터 수정 후보의 원천 대조와 실패한 검수 단계의 실제 증거다. 이번 문서와 모델 응답은 목표 달성 인증서가 아니다.
